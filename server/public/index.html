First, add it to your Home Screen

  1. Tap Share in Safari's toolbar
  2. Choose Add to Home Screen
  3. Open Beam from your Home Screen

iPhone only allows notifications for apps opened from the Home Screen.

Pair your laptop

Type the code Beam shows on your laptop. To get a new one: Beam → Settings → Pair a phone.

Add to the Share button

Apple doesn't let web apps appear in the Share button, so we'll make a tiny Shortcut that does the sending. You only do this once.

1
Copy your private link

It already contains your key, so keep it to yourself.

2
Create a new Shortcut

Tap the name at the top, choose Rename, and call it Send to Laptop.

Open Shortcuts
3
Show it in the Share button

Tap the name at the top again → Details → turn on Show in Share Sheet → Done.

Show in Share Sheet
4
Add “Get Contents of URL”

Tap Search Actions at the bottom, search Get Contents of URL and tap it. Tap the blue URL and paste your link.

Get contents of beam…workers.dev
5
Set it to send the file

Tap the › arrow on that action, then set:

MethodPOST
Request BodyForm
FilefileShortcut Input

Tap Add new field → File. Type file as the key. Tap the value and pick Shortcut Input.

6
Try it

Open Photos, pick a photo, tap Share → Send to Laptop. The first time, iPhone asks to allow the connection: tap Always Allow.

Want to send Safari links too? Make a second Shortcut called Send Link to Laptop the same way, but in step 5 add a Text field (key text) instead of a File field.
